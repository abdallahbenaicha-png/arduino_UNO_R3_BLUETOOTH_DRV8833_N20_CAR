# arduino_UNO_R3_BLUETOOTH_DRV8833_N20_CAR
🚗 Arduino UNO R3 Bluetooth Smart Car (DRV8833 + N20 Motors)
🧠 Project Description

This project is a Bluetooth-controlled smart robot car built using an Arduino IDE and an Arduino UNO R3.

The system uses a DRV8833 Motor Driver to control two N20 DC motors in a differential drive configuration.

A Bluetooth module (HC-05 / HC-06) enables real-time wireless control from an Android application.

⚙️ System Overview
📡 Receives commands via Bluetooth Serial communication
🔁 Interprets movement commands:
Forward (GO)
Backward (BACK)
Left (LEFT)
Right (RIGHT)
Spin Clockwise / Counter-Clockwise
Stop (STOP)
⚡ Controls motors through DRV8833 driver (IN1–IN4)
💡 LED indicators show movement direction
🧠 Embedded real-time control logic
